Herdr Mobile

Điều khiển các phiên herdr (Claude Code, Codex…) trên máy tính từ iPhone.

Xem terminal trực tiếp, gõ lệnh, gửi ảnh và file cho agent, duyệt yêu cầu cấp quyền ngay từ thông báo trên màn khoá. App kết nối thẳng tới máy tính của bạn qua Tailscale; không có máy chủ trung gian của nhà phát triển.

Cài đặt

  1. Cài Tailscale trên máy tính và iPhone, đăng nhập cùng một tài khoản.
  2. Cài herdr trên máy tính và chạy các agent (Claude Code, Codex…) trong herdr.
  3. Cài herdr-bridge trên đúng máy đang chạy herdr (xem lệnh bên dưới).
  4. Chạy herdr-bridge pair, mở app, vào tab Máy, bấm "Thêm máy" rồi quét mã QR (hoặc nhập mã 6 số).

macOS / Linux

curl -fsSL https://github.com/hoanghungbk93/HerdrMobile/releases/latest/download/install.sh | sh
herdr-bridge pair

Windows (herdr chạy trực tiếp trên Windows)

Mở PowerShell:

irm https://github.com/hoanghungbk93/HerdrMobile/releases/latest/download/install.ps1 | iex
herdr-bridge pair

Bấm Yes khi Windows hỏi quyền để mở cổng 7420 trên tường lửa.

Windows + WSL (herdr chạy trong WSL)

Tailscale cài trên Windows, bridge cài trong WSL (cùng chỗ với herdr). Cần Windows 11 22H2 trở lên.

  1. PowerShell thường: bật chế độ mạng mirrored để WSL dùng chung địa chỉ Tailscale của Windows, rồi khởi động lại WSL: 
    Add-Content -Encoding ascii "$env:USERPROFILE\.wslconfig" "`n[wsl2]`nnetworkingMode=mirrored"
wsl --shutdown
  2. PowerShell Run as Administrator: cho phép kết nối từ ngoài vào WSL: 
    Set-NetFirewallHyperVVMSetting -Name '{40E0AC32-46A5-438A-A0B2-2B479E8F2E90}' -DefaultInboundAction Allow
  3. Mở WSL, kiểm tra thấy địa chỉ 100.x của Tailscale rồi cài bridge: 
    ip -4 addr | grep 100.
curl -fsSL https://github.com/hoanghungbk93/HerdrMobile/releases/latest/download/install.sh | sh
herdr-bridge pair

Nếu trước đó đã cài bridge bản Windows thì gỡ đi (herdr-bridge uninstall trong PowerShell) để trả cổng 7420 cho bridge trong WSL.

Support (English)

Setup: install Tailscale on your computer and iPhone, install herdr, then install the bridge on the machine running herdr (commands above: install.sh for macOS/Linux/WSL, install.ps1 for Windows) and run herdr-bridge pair.

Herdr Mobile lets you watch and control herdr terminal sessions running on your own computer, over your Tailscale network. For help or bug reports, open an issue at GitHub Issues.
