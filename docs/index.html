Herdr Mobile

Control herdr sessions (Claude Code, Codex…) on your computer from your iPhone.

Watch terminals live, type commands, send photos and files to agents, and approve permission requests right from the lock screen notification. The app connects directly to your computer over Tailscale; there is no intermediary server run by the developer.

Get Herdr on the App Store

Installation

  1. Install Tailscale on your computer and iPhone, and sign in with the same account.
  2. Install herdr on your computer and run your agents (Claude Code, Codex…) inside herdr.
  3. Install herdr-bridge on the same machine that runs herdr (see the commands below).
  4. Run herdr-bridge pair, open the app, go to the Machines tab, tap "Add machine" and scan the QR code (or enter the 6-digit code).

macOS / Linux

curl -fsSL https://github.com/hoanghungbk93/HerdrMobile/releases/latest/download/install.sh | sh
herdr-bridge pair

Windows (herdr running directly on Windows)

Open PowerShell:

irm https://github.com/hoanghungbk93/HerdrMobile/releases/latest/download/install.ps1 | iex
herdr-bridge pair

Click Yes when Windows asks for permission to open port 7420 in the firewall.

Windows + WSL (herdr running in WSL)

Tailscale is installed on Windows, the bridge is installed inside WSL (where herdr is). Leave WSL on the default networking mode (NAT); mirrored mode is not needed.

  1. In WSL: 
    curl -fsSL https://github.com/hoanghungbk93/HerdrMobile/releases/latest/download/install.sh | sh
    The installer makes the bridge listen on 0.0.0.0 and puts the Windows Tailscale address in the QR code (if it can't read it: herdr-bridge config host 100.x.y.z). The installer changes nothing on the Windows side.
  2. On Windows, in PowerShell with Run as Administrator (one time only), replace 100.x.y.z with the Windows Tailscale IP: 
    netsh interface portproxy add v4tov4 listenaddress=100.x.y.z listenport=7420 connectaddress=127.0.0.1 connectport=7420
netsh advfirewall firewall add rule name=herdr-bridge dir=in action=allow protocol=TCP localport=7420 profile=any
  3. In WSL: herdr-bridge pair, then scan the QR code.

If you previously installed the Windows version of the bridge, remove it (herdr-bridge uninstall in PowerShell) so it doesn't compete for port 7420.
